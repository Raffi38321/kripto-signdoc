Pertanyaan Sering Diajukan

Apakah tanda tangan digital ini sah secara hukum?

SignDoc dibuat untuk tujuan pembelajaran dan demonstrasi. Untuk keperluan legal yang serius, konsultasikan dengan ahli hukum dan patuhi regulasi lokal.

Bagaimana jika saya lupa kunci privat?

Kunci privat tidak dapat dipulihkan jika hilang. Pastikan Anda membuat backup di tempat aman.

Apakah data saya aman?

Ya! Semua proses dilakukan di browser Anda. Data tidak dikirim ke server manapun.

Browser mana yang didukung?

Chrome, Firefox, Safari, dan Edge (versi terbaru). Pastikan JavaScript diaktifkan.
