#️⃣ Contoh Hash SHA-256

Berikut adalah contoh hash SHA-256 dari dokumen-dokumen di atas:

Hash dari Perjanjian Kerjasama:

a3c2d1f4e9b8c7a6d5e4f3a2b1c0d9e8f7a6b5c4d3e2f1a0b9c8d7e6f5a4b3

Catatan: Hash ini hanya contoh. Hash sebenarnya akan dihitung otomatis oleh aplikasi saat Anda mengklik "Hitung Hash SHA-256".

💡 Penting tentang Hash:
  • Hash selalu 64 karakter heksadesimal untuk SHA-256
  • Hash yang sama berarti dokumen 100% identik
  • Perubahan 1 karakter akan mengubah hash sepenuhnya
  • Tidak bisa "mundur" dari hash ke dokumen original

🔐 Contoh Kunci RSA-2048

Untuk testing, Anda bisa menggunakan contoh kunci di bawah (JANGAN GUNAKAN DI PRODUCTION):

Format Kunci Publik RSA-2048:

-----BEGIN PUBLIC KEY----- MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA1234567890... [Kunci publik akan sangat panjang, biasanya ribuan karakter] ...0987654321AQAB -----END PUBLIC KEY-----

Format Kunci Privat RSA-2048:

-----BEGIN RSA PRIVATE KEY----- MIIEowIBAAKCAQEA1234567890... [Kunci privat akan SANGAT panjang, biasanya lebih dari 3000 karakter] ...0987654321AQAB -----END RSA PRIVATE KEY-----
✅ Untuk Generate Kunci Sendiri:
  • Buka tab "Pembangkitan Kunci"
  • Klik "🔄 Generate Kunci RSA-2048"
  • Tunggu hingga selesai
  • Kunci akan dibangkitkan secara unik untuk Anda

🔄 Workflow Demo Lengkap

Langkah 1: Generate Kunci

Pertama, Anda perlu membuat pasangan kunci RSA-2048. Pergi ke tab "Pembangkitan Kunci" dan klik "Generate Kunci RSA-2048". Proses ini memakan waktu 10-30 detik.

Langkah 2: Tanda Tangani Dokumen
  1. Pergi ke tab "Tanda Tangan Dokumen"
  2. Copy salah satu dokumen contoh dari bagian di atas
  3. Paste di field "Dokumen untuk ditandatangani"
  4. Klik "Hitung Hash SHA-256" (akan menampilkan hash 64 karakter)
  5. Paste kunci privat Anda dari Tab 1
  6. Klik "Tanda Tangan Dokumen"
  7. Signature akan ditampilkan (string panjang)
Langkah 3: Verifikasi Tanda Tangan
  1. Pergi ke tab "Verifikasi Tanda Tangan"
  2. Paste dokumen original yang telah ditandatangani
  3. Paste tanda tangan dari Langkah 2
  4. Paste kunci publik Anda
  5. Klik "Verifikasi Tanda Tangan"
  6. Hasil akan menunjukkan "✅ Valid" atau "❌ Invalid"
✅ Tips untuk Testing:
  • Coba ubah 1 karakter di dokumen, lalu verifikasi lagi - akan menjadi Invalid
  • Coba gunakan kunci publik yang berbeda - akan menjadi Invalid
  • Tanda tangan hanya valid untuk dokumen yang ditandatangani tersebut

✅ Testing Checklist

Gunakan checklist ini untuk menguji semua fitur aplikasi:

Tab 1: Pembangkitan Kunci

  • Generate kunci RSA-2048 (tunggu 10-30 detik)
  • Kunci publik ditampilkan
  • Kunci privat ditampilkan
  • Bisa copy kunci publik
  • Bisa copy kunci privat
  • Bisa download kunci privat
  • Bisa download semua kunci

Tab 2: Tanda Tangan Dokumen

  • Input teks dokumen
  • Upload file
  • Hitung hash SHA-256 (64 karakter hex)
  • Input kunci privat
  • Tanda tangani dokumen
  • Signature ditampilkan
  • Bisa copy signature
  • Bisa download signature
  • Bisa download dokumen bertanda tangan

Tab 3: Verifikasi Tanda Tangan

  • Input dokumen original
  • Input signature
  • Input kunci publik
  • Verifikasi dengan signature yang benar = Valid ✅
  • Verifikasi dengan dokumen yang diubah = Invalid ❌
  • Verifikasi dengan kunci publik salah = Invalid ❌
  • Hash dokumen ditampilkan
  • Status verifikasi ditampilkan

🔧 Troubleshooting

❌ Tombol Generate Kunci tidak berfungsi

  • Pastikan JavaScript diaktifkan di browser
  • Coba refresh halaman (F5)
  • Coba gunakan browser lain (Chrome, Firefox, Edge)

❌ Error "Gagal membuat signature"

  • Pastikan kunci privat valid (dimulai dengan "-----BEGIN RSA PRIVATE KEY-----")
  • Jangan ada spasi atau karakter tambahan saat copy-paste
  • Pastikan dokumen telah di-hash terlebih dahulu

❌ Verifikasi selalu Invalid padahal seharusnya Valid

  • Pastikan dokumen yang diverifikasi 100% sama dengan yang ditandatangani
  • Pastikan kunci publik sama dengan kunci publik penanda tangan
  • Cek apakah ada spasi atau baris kosong yang terlewat

❌ Browser tidak bisa download file

  • Cek pengaturan firewall atau antivirus
  • Pastikan folder download memiliki permission yang cukup
  • Coba browser lain
