Tutorial Lengkap Tanda Tangan Digital

1️⃣ Apa Itu SignDoc?

SignDoc adalah aplikasi web untuk membuat dan memverifikasi tanda tangan digital pada dokumen. Menggunakan teknologi enkripsi RSA-2048 dan hash SHA-256 untuk menjamin keaslian dan integritas dokumen.

💡 Penting: Semua proses kriptografi dilakukan di browser Anda. Data Anda aman dan tidak pernah dikirim ke server.

2️⃣ Konsep Dasar Kriptografi

RSA-2048 (Asymmetric Encryption)

RSA adalah algoritma enkripsi kunci publik. Menggunakan sepasang kunci:

  • Kunci Publik: Dibagikan ke siapa saja, digunakan untuk verifikasi
  • Kunci Privat: Disimpan rahasia, digunakan untuk membuat tanda tangan

Keamanan: 2048-bit = 2^2048 kemungkinan, sangat aman dengan teknologi saat ini.

SHA-256 (Hash Function)

SHA-256 mengubah dokumen menjadi "fingerprint" unik 256-bit.

Contoh: Input: "Saya setuju dengan perjanjian ini" Output: "a3c2d1f4e9b8c7a6d5e4f3a2b1c0d9e8f7a6b5c4d3e2f1a0b9c8d7e6f5a4b3" Input: "Saya setuju dengan perjanjian itu" (perubahan kecil) Output: "b9f4e2a1d8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0c9b8a7f6e5d4c3b2"

Karakteristik penting:

  • One-Way: Tidak bisa dikembalikan ke data original
  • Deterministic: Data sama selalu menghasilkan hash sama
  • Collision Resistant: Hampir mustahil ada dua data dengan hash sama

3️⃣ Langkah-Langkah Penggunaan

✅ Langkah 1: Generate Kunci RSA-2048

Tujuan: Membuat pasangan kunci publik dan privat
  1. Buka tab "Pembangkitan Kunci"
  2. Klik tombol "🔄 Generate Kunci RSA-2048"
  3. Tunggu 10-30 detik proses pembangkitan selesai
  4. Kunci Publik akan ditampilkan (boleh dibagikan)
  5. Kunci Privat akan ditampilkan (JANGAN BAGIKAN)
  6. Klik "⬇️ Download" untuk menyimpan kunci privat
⚠️ PENTING: Download dan simpan kunci privat di tempat aman! Jangan bagikan kunci privat kepada siapapun.

✅ Langkah 2: Tanda Tangan Dokumen

Tujuan: Membuat tanda tangan digital untuk dokumen
  1. Buka tab "Tanda Tangan Dokumen"
  2. Input dokumen:
    • Ketik langsung di text area, ATAU
    • Upload file (TXT, PDF, DOC, DOCX)
  3. Klik "#️⃣ Hitung Hash SHA-256"
  4. Hash dokumen akan ditampilkan (tulisan panjang heksadesimal)
  5. Paste kunci privat Anda di field "Kunci Privat"
  6. Klik "✍️ Tanda Tangan Dokumen"
  7. Tanda tangan digital akan dihasilkan
  8. Download hasil jika diperlukan

✅ Langkah 3: Verifikasi Tanda Tangan

Tujuan: Memverifikasi keaslian dan integritas dokumen
  1. Buka tab "Verifikasi Tanda Tangan"
  2. Input dokumen original di field "Dokumen Original"
  3. Paste tanda tangan di field "Tanda Tangan (Signature)"
  4. Paste kunci publik penanda tangan di field "Kunci Publik"
  5. Klik "✅ Verifikasi Tanda Tangan"
  6. Lihat hasil verifikasi:
    • ✅ Valid: Dokumen asli dan tidak diubah
    • ❌ Invalid: Dokumen telah diubah atau tanda tangan tidak sah

4️⃣ Skenario Praktis: Notaris Digital

Kasus: Perjanjian Kerjasama

Roni dan Ria ingin menandatangani perjanjian kerjasama. Mereka tidak bisa bertemu langsung. Bagaimana menggunakan SignDoc?

📋 Alur Proses:

HARI 1 - Roni Menandatangani

  1. Roni buka SignDoc
  2. Tab Pembangkitan Kunci → Generate kunci RSA-2048
  3. Download kunci privat (simpan aman) → Kirim kunci publik ke Ria
  4. Tab Tanda Tangan → Input dokumen perjanjian
  5. Hitung Hash SHA-256
  6. Paste kunci privat → Tanda tangani dokumen
  7. Download tanda tangan → Kirim ke Ria

HARI 2 - Ria Memverifikasi

  1. Ria terima dokumen dan tanda tangan dari Roni
  2. Ria buka SignDoc
  3. Tab Verifikasi → Input dokumen original
  4. Input tanda tangan dari Roni
  5. Input kunci publik Roni
  6. Klik Verifikasi
  7. Hasil: ✅ Valid = Dokumen asli dari Roni, tidak diubah
✅ Hasil: Ria percaya bahwa dokumen benar-benar dari Roni dan belum diubah. Perjanjian sah secara digital.

6️⃣ Tips Keamanan 🔐

1. Kunci Privat
✓ Simpan di tempat aman (encrypted folder, safe deposit box) ✓ Buat backup di berbagai lokasi ✗ JANGAN kirim via email atau chat ✗ JANGAN bagikan dengan siapapun ✗ JANGAN simpan di public folder
2. Verifikasi Kunci Publik
✓ Pastikan kunci publik dari sumber terpercaya ✓ Mintalah kunci publik langsung dari orang bersangkutan ✗ JANGAN percaya kunci publik dari pihak ketiga
3. Penggunaan Browser
✓ Gunakan browser terkini dengan update keamanan terbaru ✓ Gunakan antivirus/antimalware ✗ JANGAN gunakan di komputer terinfeksi malware ✗ JANGAN gunakan internet publik tanpa VPN
4. Proses Verifikasi
✓ Selalu verifikasi dokumen penting ✓ Pastikan hash cocok sebelum menerima dokumen ✗ JANGAN terima dokumen tanpa verifikasi

7️⃣ Pertanyaan Umum (FAQ)

❓ Apa itu RSA-2048?

RSA adalah algoritma enkripsi. 2048 adalah ukuran kunci (2048 bits). Semakin besar angka, semakin sulit dipecahkan. 2048 bits sangat aman untuk penggunaan umum.

❓ Bagaimana jika saya lupa kunci privat?

Tidak bisa dipulihkan! Pastikan Anda membuat backup. Rekomendasikan: Simpan 2-3 copy di tempat berbeda.

❓ Bisakah saya menggunakan aplikasi ini offline?

Ya! Download semua file (index.html, styles.css, app.js) dan buka index.html di browser. Semua proses dilakukan lokal di komputer Anda.

❓ Apakah tanda tangan digital sah secara hukum?

Itu tergantung hukum di negara Anda. SignDoc dibuat untuk tujuan pembelajaran. Untuk dokumen legal, konsultasikan dengan ahli hukum.

❓ Bisakah orang lain memalsukan tanda tangan saya?

Sangat sulit! Untuk memalsukan, mereka perlu kunci privat Anda. Jika Anda menjaga kunci privat dengan aman, tanda tangan Anda aman.

❓ Berapa lama hash SHA-256 valid?

Hash tidak "hangus". Selama dokumen tidak berubah, hash akan selalu sama. Anda bisa memverifikasi dokumen berusia puluhan tahun sekalipun.
